🎧 yash.album — A Social Media Photo Album App
yash.album is a modern, dark-themed social media platform focused on sharing and showcasing photo albums. Built using Next.js and Supabase, it features a custom authentication system with JWT + cookie-based login, and uses MongoDB with Mongoose to handle user and post data.

The UI is sleek and interactive, enhanced with:

Tailwind CSS for utility-first styling

Framer Motion for smooth animations

Lucide Icons for clean, modern iconography

Animated particle background to give it a lively, immersive feel

Core Features:

User signup/login with custom auth flow

Profile pages displaying user info and albums

Post components for uploading and viewing photos

JWT-authenticated routes for secure access

MongoDB schemas for users and posts, managed with Mongoose

This project showcases your skills in full-stack development, custom authentication, and modern UI/UX design.
